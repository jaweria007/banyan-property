# 6. Supply Overview Page 
The Supply Overview page provides valuable inventory insights, but the current interface feels very basic and table-heavy. The objective is to modernize the layout, improve data visualization, and create a cleaner dashboard experience while preserving all existing functionality.

---

## Summary Cards

The top summary containers (Inventory by Property Type, Workflow Distribution, Rentals Price Bands, Villa Sales Price Bands, Land Price Bands, etc.) currently use simple white cards with tables.

### Improvements

- Redesign all summary cards with a more modern appearance.
- Introduce subtle gradients using the Banyan color palette.
- Add soft shadows and rounded corners.
- Improve typography hierarchy for titles and values.
- Increase internal spacing and padding.
- Use accent colors to highlight important numbers.
- Add subtle hover interactions.
- Replace the plain table look with a cleaner dashboard card style while maintaining readability.

The current boxes feel too basic and should be redesigned to better match the premium look of the updated dashboard.

---

## Layout Improvements

The current arrangement leaves some unused space that can be utilized more efficiently.

### Improvements

- Place the **Inventory by Area** container beside the **Land Price Bands** card to create a more balanced layout.
- Reduce unnecessary vertical scrolling.
- Maintain consistent spacing between all dashboard sections.
- Ensure the layout remains fully responsive across different screen sizes.

This adjustment will improve the overall visual balance and make better use of the available screen space.

---

## Inventory by Area

The expandable area list is useful but visually plain.

### Improvements

- Improve the styling of expandable rows.
- Add modern accordion indicators.
- Enhance active and hover states.
- Improve spacing and typography.
- Better highlight the selected or expanded area.
- Use subtle color accents for mapped and unmapped inventory.

---

## Data Tables

The detailed inventory tables should receive a complete visual refresh.

### Improvements

- Improve table header styling.
- Increase row spacing for better readability.
- Add alternating row backgrounds or subtle separators.
- Improve alignment of numerical values.
- Add hover states to table rows.
- Use better typography hierarchy for labels and totals.
- Highlight important totals with the project's accent colors.

The tables should feel cleaner and easier to scan while maintaining all existing data.

---

## Visual Hierarchy

Improve the organization of information across the page.

### Improvements

- Better grouping of related sections.
- Consistent spacing throughout the layout.
- Improved section headings.
- Softer shadows.
- Consistent border radius.
- Better use of white space.

---

## General UI Enhancements

Additional improvements may include:

- Modern dashboard styling.
- Improved responsiveness.
- Cleaner typography.
- Smooth hover and transition animations.
- Consistent use of the Banyan design system.
- Better visual hierarchy across all dashboard components.

The objective is to transform the Supply Overview page into a modern analytics dashboard that feels polished, organized, and visually consistent with the redesigned Overview and Listings pages.
