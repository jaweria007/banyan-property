# 5. Sign In Page Improvements

The current sign-in page is simple and functional but lacks branding and visual appeal. The objective is to redesign it into a modern, premium login experience that aligns with the overall Banyan Dashboard UI.

---

## Background

The current plain light-gray background should be replaced with a more branded appearance.

### Improvements

- Use the Banyan primary green (`#1A3D35`) as the main background color.
- Add a subtle gradient or abstract background pattern to create depth.
- Keep the background clean and minimal without becoming distracting.
- Ensure the login form remains the primary focus.

---

## Login Card

The login form should be redesigned with a modern glassmorphism effect.

### Improvements

- Use a white translucent card.
- Apply a glassmorphism effect using:
  - Background blur
  - Semi-transparent white background
  - Soft border
  - Soft shadow
- Increase border radius for a more premium appearance.
- Improve internal spacing and typography.
- Ensure the card is perfectly centered on the screen.

---

## Branding

Use the official **`banyan-logo.png`** from the project's **assets** folder instead of the current emoji/logo.

### Improvements

- Place the Banyan logo at the top of the login card.
- Maintain proper spacing between the logo, title, and form.
- Keep the branding clean and professional.

---

## Form Fields

Modernize the email and password inputs.

### Improvements

- Increase input height.
- Add subtle borders.
- Improve focus states using the Banyan green accent.
- Add smooth focus animations.
- Maintain consistent spacing between labels and inputs.

---

## Sign In Button

The primary action button should better reflect the new design system.

### Improvements

- Full-width button.
- Rounded corners.
- Dark green background (`#1A3D35`).
- White text.
- Smooth hover and active animations.
- Slight shadow to create depth.

---

## Typography

Improve the visual hierarchy throughout the page.

### Improvements

- Larger page title.
- Softer subtitle.
- Better label spacing.
- Consistent font weights.
- Improve readability across the form.

---

## Overall Design Goal

The redesigned Sign In page should feel modern, premium, and welcoming while maintaining simplicity.

Use the Banyan design system throughout the page:

- White (`#FFFFFF`)
- Dark Green (`#1A3D35`)
- Cream (`#EFDBB3`)
- Dark Gray (`#555555`)
- Gold Accent (`#977D4A`)

The final design should combine clean minimalism with a subtle glassmorphism aesthetic, creating a polished first impression that matches the rest of the redesigned dashboard.
