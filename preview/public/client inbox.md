# 7. Client Inbox Page Improvements

The Client Inbox page is already structurally good and provides the required information clearly. The overall layout can be retained, but the visual design should be enhanced to make the page feel more modern, polished, and consistent with the redesigned Banyan dashboard.

## Summary / Status Cards

The five cards at the top:

- Proposal Not Opened
- Follow-up Overdue
- Viewing Today
- Waiting on Client
- Negotiation Stalled

currently appear as a simple row and end too early, leaving a large amount of unused horizontal space.

### Improvements

- Redesign the five cards with a more modern dashboard style.
- Use subtle gradients, soft shadows, and rounded corners.
- Improve the number-to-label hierarchy.
- Use small icons or visual indicators where appropriate.
- Use the Banyan color palette for status accents.
- Give the cards slightly more visual depth without making them overly decorative.

### Card Arrangement

The five cards should be arranged so that they **use the available content width more effectively** rather than stopping after a small portion of the page.

Possible approaches:

- Make the cards evenly distributed across the available width.
- Increase their width while maintaining consistent spacing.
- Ensure the row feels balanced from left to right.
- Keep the layout responsive so the cards wrap naturally on smaller screens.

The objective is for the top section to feel intentional and balanced rather than like five small boxes placed at the beginning of a large empty area.

---

## Search & Filter Area

The search and filtering area is functional but can be visually refined.

### Improvements

- Modernize the search input.
- Improve dropdown styling.
- Use consistent heights across all controls.
- Improve spacing between filters.
- Refine the Filter button.
- Add subtle hover and focus states.
- Keep the entire filter row visually aligned.

---

## Client Table

The table is currently clean and readable, so the structure can remain largely unchanged while improving the visual treatment.

### Improvements

- Improve table header styling.
- Increase row spacing slightly.
- Add subtle row hover effects.
- Improve typography hierarchy.
- Better distinguish client names from secondary information such as phone numbers.
- Improve alignment between columns.
- Use subtle separators rather than heavy borders.
- Highlight important information such as priority and follow-up status.

---

## Status & Priority Indicators

Information such as:

- Follow-up Overdue
- High Priority
- Medium Priority

should be represented through polished visual indicators.

### Improvements

- Use compact pill-style containers.
- Apply appropriate status colors.
- Keep indicators small and unobtrusive.
- Use consistent border radius and typography.
- Ensure they look like informational status chips rather than traditional buttons.

---

## Overall UI Enhancement

The complete Client Inbox page should receive a visual polish while keeping its current structure and functionality.

Enhance:

- Cards
- Table
- Search
- Filters
- Status indicators
- Typography
- Spacing
- Shadows
- Border radius
- Hover states
- Responsive behavior

The page should follow the same Banyan design system used across the Overview, Listings, Availability, and Supply Overview pages.

---

## Design Direction

Use the existing Banyan color palette:

- White — `#FFFFFF`
- Dark Green — `#1A3D35`
- Cream — `#EFDBB3`
- Dark Gray — `#555555`
- Gold Accent — `#977D4A`

Keep the design **clean, premium, modern, and professional**.

Do not unnecessarily change the existing information architecture or functionality. The focus is on **enhancing the UI and visual hierarchy** while making better use of the available screen space.
