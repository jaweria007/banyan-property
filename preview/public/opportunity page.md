# 8. Opportunities Page Improvements

The Opportunities page is functional and the overall structure is clear, but the current interface feels very basic and heavily table-based. The goal is to enhance the UI, improve visual hierarchy, and make the opportunity management experience feel more modern and premium while keeping the existing functionality intact.

---

## Page Header

The current header contains the Opportunities title, total count, description, and **+ New Opportunity** action.

### Improvements

- Create a stronger visual hierarchy for the page title and opportunity count.
- Improve spacing between the title, description, and action.
- Redesign the **+ New Opportunity** button with a more premium appearance.
- Add subtle hover and active states.
- Keep the primary action clearly visible and easy to access.

---

## Search & Filters

The search and filtering section should be visually refined.

### Improvements

- Modernize the search field.
- Improve dropdown styling.
- Keep all filter controls consistent in height and spacing.
- Improve the Filter button styling.
- Add clear focus and hover states.
- Consider grouping the filters into a visually cohesive filter bar.
- Ensure the filter area works well responsively.

---

## Opportunities Table

The current table contains the main opportunity information but has a very plain appearance.

### Improvements

- Redesign the table container with a modern card-style appearance.
- Improve the table header hierarchy.
- Add more comfortable row spacing.
- Use subtle separators instead of heavy borders.
- Add hover states to rows.
- Improve alignment between columns.
- Make important information easier to scan.
- Maintain consistent typography throughout the table.

---

## Priority Indicator

The current **Med** priority value uses a small colored dot.

### Improvements

Turn priority values into small informational pill/chip containers.

Examples:

- High
- Med
- Low

These should be **informational containers, not buttons**.

Use subtle background colors and rounded corners so the priority can be identified quickly without visually overwhelming the table.

---

## Pipeline Status

The **New** pipeline value should also have a more polished visual treatment.

### Improvements

- Use a small status chip or badge.
- Apply subtle background styling.
- Keep the design consistent with the priority indicators.
- Use the Banyan color palette for status accents.

---

## Action Links

The current **Build Shortlist** and **Profile** links appear as plain text.

### Improvements

- Improve their visual hierarchy.
- Add subtle hover effects.
- Consider using small icons where appropriate.
- Keep them visually distinct from normal table content.
- Maintain a compact appearance so the Actions column does not become visually heavy.

---

## New Opportunity Button

The **+ New Opportunity** action is an important primary action.

### Improvements

- Keep it visually prominent.
- Use Banyan dark green (`#1A3D35`).
- Add a subtle shadow.
- Use rounded corners.
- Add smooth hover/press transitions.
- Consider a small plus icon rather than relying only on text.

---

## Table Data & Empty States

Some rows currently contain missing values represented by `—`.

### Improvements

- Use a consistent muted treatment for unavailable information.
- Avoid making missing data look like an error.
- Maintain alignment even when information is unavailable.

---

## Overall UI Enhancement

The Opportunities page should follow the same visual language as the redesigned Banyan dashboard.

Enhance:

- Page header
- New Opportunity action
- Search
- Filters
- Table
- Priority indicators
- Pipeline indicators
- Action links
- Spacing
- Typography
- Shadows
- Border radius
- Hover states
- Responsive behavior

---

## Design Direction

Use the existing Banyan color palette:

- White — `#FFFFFF`
- Dark Green — `#1A3D35`
- Cream — `#EFDBB3`
- Dark Gray — `#555555`
- Gold Accent — `#977D4A`

The overall direction should be **clean, modern, premium, and professional**.

Do not change the existing functionality or data structure. The focus is on improving the visual experience, hierarchy, readability, and consistency of the Opportunities page.
